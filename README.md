# Construction Procurement OS

Independent product and workflow project translating practical procurement experience into a structured digital procurement system.

## What the project is trying to solve

The system is designed around recurring procurement problems seen in day-to-day operations: fragmented requests, inconsistent supplier quotations, weak comparison trails, approval ambiguity and poor visibility from requirement through commitment.

The intended workflow covers:

- material/service requisitions;
- RFQs and supplier participation;
- quotation capture and normalization;
- commercial comparison;
- approvals and award decisions;
- purchase commitments and records;
- supplier and procurement reporting;
- auditability and change history.

## AI-assisted development approach

The project is being developed with AI coding and review tools, including Codex and Claude Code, while keeping the procurement logic and acceptance criteria explicitly controlled.

The working approach includes:

- requirements defined before implementation;
- Git-based version control and traceability;
- staged build phases and acceptance gates;
- independent review of AI-generated work;
- explicit change control instead of silently rewriting requirements;
- validation before progressing to later procurement and AI features.

The objective is not simply to generate code with AI, but to test how AI agents can support structured product development while preserving business-process ownership and review discipline.

## Current status

The project is under active staged development. Core architecture and build sequencing have been established, with implementation progressing through controlled blocks rather than presenting unfinished functionality as a completed commercial product.
