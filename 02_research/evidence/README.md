# Evidence Register

Evidence is stored in stable ID ranges rather than one ever-growing CSV.

## Current inherited retro-file snapshot

- `retrofile/EVD_0001_0045.csv`
- `retrofile/EVD_0046_0090.csv`
- `retrofile/EVD_0091_0135.csv`
- `retrofile/EVD_0136_0178.csv`

These records preserve the v0.1 intelligence state. `PROPOSED` means not yet source-verified. `CONTESTED` means an old conclusion was explicitly demoted to hypothesis.

## Rule

Evidence IDs are permanent. Verification updates status/confidence/source linkage; it does not renumber the claim. New evidence continues with the next unused EVD ID.
