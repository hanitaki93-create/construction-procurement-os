# CHG-0004 — CP-05 Control Tightening

**Decision:** ACCEPTED / IMPLEMENTED
**Trigger:** CP-05 hostile critique

## Change
- retire ambiguous `P1_0_SUFFICIENT` evidence-dependency label;
- require `PRIMARY_REQUIRED` or `DESIGN_PHASE` for unresolved architecture ADRs as applicable;
- force ADR-0003/0004/0005 to remain PRIMARY_REQUIRED;
- add decision-bearing source preservation policy;
- add concise independent inspection bundle;
- issue Control v0.3 and Audit Protocol v1.2.

## Deliberate modification to critique
The critique requested archival capture for every cited external page. This is rejected as overbroad because background/deferred competitor claims cannot currently freeze architecture and exhaustive archival would recreate claim-volume bureaucracy. Immutable source preservation is mandatory at promotion to accepted/frozen decision use; otherwise the source must be re-verified when promoted.

## Impact
P1.0 process/control only. Phase sequence and product scope unchanged.
