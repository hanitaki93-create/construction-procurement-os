# 1. Method

Each thread in `P1_11_GOLDEN_THREAD_ATLAS_V0_1.md` was executed against the frozen P1.4–P1.10 contracts and the builder-facing action/surface/API catalogue.

A thread fails if any step requires invention of:

- authoritative owner;
- subject/fact identity;
- lifecycle/state/guard;
- operation/authority/evidence;
- commercial effect/correction;
- event/communication/effect stage;
- report population/time/use;
- interaction/confirmation/recovery;
- NFR/security/residency behavior;
- AI authority/context/evaluation behavior.

Physical choices such as database, endpoint syntax, screen layout or provider are not architecture questions when the frozen contract already determines required meaning.
