# Repository Conventions

## Numbered top-level directories
Top-level numbers express logical lifecycle, not chronological completion.

## File names
Use uppercase for canonical control artifacts and normal snake_case for working artifacts.

## IDs
- SRC-#### source
- EVD-#### evidence
- ASM-#### assumption
- Q-#### question
- CON-#### contradiction
- ADR-#### architecture decision
- REQ-#### requirement
- CHG-#### architecture/roadmap change
- GT-#### golden thread
- BU-#### build unit
- BG-#### build gate
- INC-#### incident/failure
- MIG-#### migration
- REL-#### release

IDs are never reused.

## Status
Every governing or execution artifact must declare status near its top.
