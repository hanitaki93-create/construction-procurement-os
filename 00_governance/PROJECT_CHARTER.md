# Project Charter

## Goal
Design, build, validate and eventually operate a contractor-focused construction procurement/commercial operating system.

## Product principle
The deterministic system owns truth. AI is additive and earns authority only after measured validation.

## Project principle
Research truth, architecture truth, implementation truth and runtime truth remain traceable but distinct.

## Non-goal
Do not recreate every enterprise construction product simply because the feature exists.

## Phase discipline
- Phase 1: deterministic architecture and product specification.
- Phase 2: dependency-aware build decomposition and gates.
- Phase 3: deterministic construction.
- Phase 4: system-truth validation, integration testing and polish.
- Phase 5: progressively validated AI/ML expansion.
